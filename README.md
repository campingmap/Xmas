# Xmas

미리 크리스마스 캠프의 모바일 우선 행사 홈페이지입니다.

- 배포: GitHub Pages, `main` 브랜치의 루트 디렉터리
- 로컬 실행: `python -m http.server 8766 --directory .`
- 화면: 모바일 전체 폭, PC 중앙 최대 500px 및 좌우 행사 브랜딩
- 기능: 날짜별 프로그램 탭, 포스터 확대, 캘린더 다운로드, FAQ
- 콘텐츠: 2026-10-27 카페 글 https://cafe.naver.com/hocamp/5099 및 제공된 공식 포스터
- 모집 일정, 참가비, 프로그램은 준비 단계의 안내이며 확정 시 수정 필요
- 장소 주소는 기존 https://campingmap.github.io/hocamp9/ 안내를 참고
- `assets/winter-camp.webp`는 생성한 분위기용 이미지로, 실제 행사장 사진이 아님
- 포스터의 12월 20일 요일 표기와 달리 실제 2026-12-20은 일요일이므로 본문에 일요일로 안내

빌드와 외부 서버 없이 HTML/CSS/JavaScript로 동작합니다. 이미지 원본과 계정 정보는 필요하지 않습니다.
캠핑유튜버들과 함께하는 미리 크리스마스 캠프

## 홈페이지 참가신청

- `register.html`: 기존 구글폼의 질문·선택지·필수 항목을 옮긴 신청 페이지.
- `registration-fields.js`: 2026-10-29 원본 구글폼에서 확인한 항목 ID 및 원문. Google에서 질문을 삭제 후 다시 만들면 ID도 다시 확인해야 합니다.
- `registration.js`: 숙소별 기본 요금 + 성인·아동 각각 2명 초과 요금 + 추가 차량 요금. 대형펜션도 성인 2명·아동 2명 기준. 다자녀 면제는 미적용.
- 추가 차량 및 금액 내역은 기존 ‘하고 싶은 말’ 응답에 덧붙입니다. 서버에서 검증한 결제 금액이 아니므로 관리자가 확인해야 합니다.
- 폼은 Google의 `formResponse`에 일반 HTML POST로 제출하며, Google 결과 화면으로 이동합니다. 숨겨진 iframe이나 읽을 수 없는 응답을 접수 성공으로 표시하지 않습니다.
- 실데이터를 사용한 제출 및 응답 저장 확인은 아직 하지 않았습니다. 운영 전 소유자가 테스트 응답의 각 열(시간·복수 선택 포함)을 확인해야 합니다. 입금 확인 기능은 포함되지 않습니다.
- 원본 소개에는 ‘제 9회 호캠프’, 개인정보 동의서 이용 목적에는 ‘호캠프 리턴즈’가 남아 있습니다. 운영자가 원본 동의 문구를 검토한 후 홈페이지 원문도 함께 갱신해야 합니다.
